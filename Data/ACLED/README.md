# ACLED data

ACLED's terms of use do not allow redistribution of its data, so the file is not included here.

To reproduce the analysis:

1. Create a free account at [acleddata.com](https://acleddata.com).
2. Download the **aggregated weekly data for Europe and Central Asia** (the file used in the paper covers weeks up to 21 March 2026).
3. Save it in this folder. Its name must start with `Europe-Central-Asia` and end in `.csv`, for example `Europe-Central-Asia_aggregated_data_up_to_week_of-2026-03-21.csv`.

The script keeps only Ukraine and Russia and the event types *Battles*, *Explosions/Remote violence* and *Violence against civilians*.
